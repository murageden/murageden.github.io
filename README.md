# Portfolio
My Portfolio: A web app that showcases my developer experience, as part of my career journey

## Development

This app is live here: [view my portflio](https://murageden.github.io)

This app was created using next.js. To develop and run, first run the development server:

```bash
git clone https://github.com/murageden/murageden.github.io.git
cd murageden.github.io
google-chrome-stable index.html
```

You can start editing the page by modifying `index.html`. The page will update after a browser refresh.


## Deploy to Github pages

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```
